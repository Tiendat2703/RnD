# Tài liệu MeetMateAI

- `design/` — hợp đồng thiết kế: `MEETMATE-DESIGN.md` (chính), `DESIGN-SUBSCRIPTION.md` (trang Gói dịch vụ), `DESIGN.md` (capture tham khảo, không dùng thương hiệu), `mockups/` (bản vẽ giao diện).
- `plans/` — kế hoạch và sổ đối chiếu theo ngày (extension, conflict register, replatform, checklist, prototype gap).
- `screenshots/` — ảnh chụp prototype, sinh bằng `node scripts/prototype-shots.mjs`.

Nguồn sự thật cho dev: `Claude.md` ở thư mục gốc.
